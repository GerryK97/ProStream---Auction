## 🎓 Key Concepts

### What's Being Deployed?
- **Frontend:** React components, pages, navigation
- **Backend:** NextAuth authentication, API endpoints
- **Database:** MongoDB for users and tournaments
- **Hosting:** Vercel (serverless)
- **OAuth:** Google Sign-in

### How It Works?
1. User visits your app
2. User clicks "Login"
3. Redirected to Google Sign-in
4. Google authenticates user
5. User created/updated in database
6. Session token created
7. User redirected to app
8. App shows user info in navigation
9. User can access protected pages

### What Permission Levels Exist?
- **Admin:** Full access to everything
- **Manager:** Can create tournaments
- **Viewer:** Can only view assigned tournaments

### How Are Permissions Checked?
- Login required for protected routes
- User role checked via API
- Tournament access verified
- Creator auto-assigned to tournament
