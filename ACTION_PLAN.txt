================================================================================
IMMEDIATE ACTION PLAN - 401 Login Error on Vercel
================================================================================

PROBLEM: You're getting 401 error when trying to login on Vercel

ROOT CAUSE: Likely missing or incorrect NEXTAUTH_URL environment variable

================================================================================
DO THIS NOW (5 MINUTES)
================================================================================

STEP 1: Check What's Actually Set
├─ Go to: https://YOUR-VERCEL-DOMAIN.vercel.app/api/debug/env-check
├─ Replace YOUR-VERCEL-DOMAIN with your actual domain
└─ Look at the JSON response - note what shows ❌

STEP 2: Get Your Correct Vercel Domain
├─ Go to Vercel Dashboard
├─ Open your project
└─ Copy the domain shown at the top (e.g., prostream-auction.vercel.app)

STEP 3: Update NEXTAUTH_URL in Vercel
├─ Go to Settings → Environment Variables
├─ Find NEXTAUTH_URL
├─ Change to: https://YOUR-DOMAIN-FROM-STEP2.vercel.app
├─ Click Save
└─ ⏱️  WAIT 2-3 MINUTES for redeploy

STEP 4: Hard Refresh Browser
├─ Go to your Vercel domain
├─ Press Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
└─ Wait for page to reload

STEP 5: Try Login
├─ Click Login button
├─ Enter: admin / Admin@123
└─ If it works - DONE! If not - continue below

================================================================================
IF STILL NOT WORKING
================================================================================

STEP 6: Check Admin User in MongoDB
├─ Go to MongoDB Atlas
├─ Click your cluster → Collections
├─ Look for 'users' collection
├─ Should have at least 1 document with username "admin"
└─ If not found - see "Seed Admin User" section

STEP 7: Try In Incognito Window
├─ Open new incognito/private window
├─ Go to your Vercel domain
├─ Try login again
└─ This avoids browser cache issues

STEP 8: Check Browser Console Errors
├─ Press F12
├─ Click Console tab
├─ Try login again
├─ Look for red error messages
└─ Note what it says

================================================================================
IF STILL STUCK - USE DEBUG ENDPOINT
================================================================================

Go to: https://YOUR-DOMAIN.vercel.app/api/debug/env-check

Look for these in the response:

✅ GOOD:
  "NEXTAUTH_URL": "https://prostream-auction-xxx.vercel.app"
  "NEXTAUTH_SECRET": "✅ SET"
  "MONGODB_URI": "✅ SET (...)"

❌ BAD:
  "NEXTAUTH_URL": "❌ NOT SET" or "http://localhost:3000"
  "NEXTAUTH_SECRET": "❌ NOT SET"
  "MONGODB_URI": "❌ NOT SET"
